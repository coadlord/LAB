Experiment 2: Stack — Postfix Evaluation

Python Program:

expression = "23*5+"
stack = []

for item in expression:
    if item.isdigit():
        stack.append(int(item))
    else:
        b = stack.pop()
        a = stack.pop()

        if item == '+':
            stack.append(a + b)
        elif item == '*':
            stack.append(a * b)

print("Result:", stack.pop())

Output:
Result: 11
