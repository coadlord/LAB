Experiment 4: Factorial, Fibonacci and Binary Search

Python Program:

# Factorial
n = 5
fact = 1

for i in range(1, n + 1):
    fact = fact * i

print("Factorial:", fact)

# Fibonacci Series
a, b = 0, 1

print("Fibonacci:", end=" ")

for i in range(7):
    print(a, end=" ")
    a, b = b, a + b

# Binary Search
numbers = [10, 20, 30, 40, 50]
key = 30

low = 0
high = len(numbers) - 1

while low <= high:
    mid = (low + high) // 2

    if numbers[mid] == key:
        print("\nElement found at index:", mid)
        break
    elif numbers[mid] < key:
        low = mid + 1
    else:
        high = mid - 1

Output:
Factorial: 120
Fibonacci: 0 1 1 2 3 5 8
Element found at index: 2
