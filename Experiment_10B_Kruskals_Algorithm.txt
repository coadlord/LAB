Experiment 10(B): Kruskal's Algorithm

Python Program:

edges = [
    (2, 0, 1),
    (3, 0, 2),
    (4, 1, 2),
    (5, 1, 3),
    (6, 2, 3)
]

edges.sort()
parent = [0, 1, 2, 3]
cost = 0

for weight, x, y in edges:
    if parent[x] != parent[y]:
        old = parent[x]

        for i in range(4):
            if parent[i] == old:
                parent[i] = parent[y]

        cost += weight
        print(x, y, weight)

print("Total cost:", cost)

Output:
0 1 2
0 2 3
1 3 5
Total cost: 10
