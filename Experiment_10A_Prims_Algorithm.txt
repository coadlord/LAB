Experiment 10(A): Prim's Algorithm

Python Program:

graph = [
    [0, 2, 3, 999],
    [2, 0, 4, 5],
    [3, 4, 0, 6],
    [999, 5, 6, 0]
]

visited = [1, 0, 0, 0]
cost = 0

for i in range(3):
    minimum = 999

    for j in range(4):
        for k in range(4):
            if visited[j] and not visited[k] and graph[j][k] < minimum:
                minimum = graph[j][k]
                x, y = j, k

    visited[y] = 1
    cost += minimum
    print(x, y, minimum)

print("Total cost:", cost)

Output:
0 1 2
0 2 3
1 3 5
Total cost: 10
