Experiment 12: Linear Search and Binary Search

Python Program:

numbers = [10, 20, 30, 40, 50]
key = 30

# Linear Search
for i in range(len(numbers)):
    if numbers[i] == key:
        print("Linear Search: Found at index", i)
        break

# Binary Search
low = 0
high = len(numbers) - 1

while low <= high:
    mid = (low + high) // 2

    if numbers[mid] == key:
        print("Binary Search: Found at index", mid)
        break
    elif numbers[mid] < key:
        low = mid + 1
    else:
        high = mid - 1

Output:
Linear Search: Found at index 2
Binary Search: Found at index 2
